# Employee Management System

A React.js web application with role-based access control 
for managing employee tasks and dashboards.

## Tech Stack
React.js · Context API · Tailwind CSS · JavaScript · localStorage

## Features
- Role-based login: Admin and Employee dashboards
- Task assignment and lifecycle management (New, Active, 
  Completed, Failed)
- Session persistence using localStorage
- Responsive UI built with Tailwind CSS

## How to Run
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:5173` in your browser

## Project Structure
- `/src/components` — Admin and Employee dashboard components
- `/src/context` — AuthContext and TaskContext
- `/src/utils` — Local storage helper functions

## Note
Currently frontend-only. Backend integration with 
Node.js, Express, and MongoDB is in progress.
